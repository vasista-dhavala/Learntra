# Learntra — AI-Powered Financial Literacy

Learntra is an AI-powered financial education and investment simulation platform designed to make financial concepts easier to understand. It helps users explore investment options, simulate financial goals, and practice stock trading using virtual money without risking real capital.

## Features

- **Financial Education:** Learn about stocks, mutual funds, SIPs, fixed deposits, and government savings schemes.
- **Personalized Investment Guidance:** Compare investment options based on financial goals, risk tolerance, and investment horizon.
- **Financial Simulations:** Explore potential outcomes for savings and investment goals.
- **Virtual Trading:** Practice buying and selling stocks with ₹1,00,000 in virtual capital.
- **AI Investment Guide:** Get contextual explanations of financial concepts, market data, and portfolio activity.
- **Simplified Learning:** Understand financial concepts through accessible language and visual explanations.

## Tech Stack

- **Frontend:** React, Vite
- **Backend:** Python, FastAPI
- **Database & Authentication:** PostgreSQL, Supabase
- **Market Data:** yfinance, MFApi.in
- **Visualizations:** Recharts, TradingView Lightweight Charts
- **AI:** Large Language Models (LLMs), Retrieval-Augmented Generation (RAG)
- **Deployment:** Vercel, Render

*The technology stack and features are planned and may evolve during development.*

## Getting Started

```bash
git clone https://github.com/vasista-dhavala/Learntra.git
cd Learntra/frontend
npm install
npm run dev
```

These commands start the frontend. Backend services and integrations must be configured separately.
